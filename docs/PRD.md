# PRD: TubeScout

## 목표
크리에이터가 "다음에 뭘 만들지"를 감이 아니라 데이터로 정하도록, 비슷한 영상들을 정량 지표로 비교하고 다음 콘텐츠를 추천한다.

## 사용자
유튜브 크리에이터. 자기 영상(또는 만들고 싶은 주제)을 기준으로, 같은 카테고리의 경쟁 영상들이 어떤 성과를 내는지 비교하고 다음 콘텐츠 방향을 잡고 싶어 하는 사람.

## 핵심 기능
1. 입력: 유튜브 영상 URL/ID 또는 주제 텍스트 한 칸. (예: `https://youtu.be/...` 또는 "백종원 레시피")
2. 분석: 시드 영상 기준으로 비슷한 영상을 검색하고, 각 영상의 정량 지표(조회수·좋아요·댓글·참여율·조회수 증가속도)를 모아 종합 점수로 순위화한다. 시드 영상도 같은 풀에 넣어 "내 영상이 몇 위인지" 보여준다.
3. 추천: 상위 영상들의 제목/태그 패턴과 지표 격차를 근거로 "다음에 만들면 좋을 콘텐츠"를 카드 형태로 제시한다.

## MVP 제외 사항
- AI/LLM 기반 콘텐츠 분석(트랜스크립트·썸네일·톤 분석)
- 로그인, 데이터베이스, 분석 히스토리 저장
- 페이지네이션/무한스크롤 (후보 영상 25~50개를 한 페이지로 표시)
- 다국어 형태소 분석기 (단순 공백/구두점 토큰화 + stopword로 대체)
- quota 캐싱·레이트리밋 대시보드

## 디자인
- 미니멀, 라이트 모드 기본. 입력은 단 한 칸으로 진입 장벽 최소화.
- 무채색 + 포인트 컬러 1가지. 점수는 막대(progress bar)로 시각화.
- 결과는 "내 영상 순위 → 비슷한 영상 순위표 → 다음 콘텐츠 추천" 순서로 위에서 아래로 읽히게 배치. 내 영상 행은 하이라이트.
